# 🧠 StudyBuddy

**StudyBuddy** is a social platform for developers to connect, chat, and collaborate through topic-based rooms.  
It allows users to share knowledge, solve problems together, and network across various areas of software development — all in a clean, interactive environment.

---

## 🚀 Features

- 💬 **Chat Rooms** – Join or create rooms for any programming topic or project.  
- 🧠 **Subject Categories** – Explore discussions categorized by technology or interest.  
- 👤 **User Profiles** – Each user can manage their bio, avatar, and hosted discussions.  
- 🔐 **Authentication** – Secure sign-up, login, and logout via Django’s built-in auth system.  
- 🔍 **Search Functionality** – Find rooms, topics, or developers quickly.  
- 🕓 **Real-Time Feel** – Chats update dynamically (refresh shows new posts instantly).  
- 📱 **Responsive Design** – Works beautifully on mobile and desktop devices.

How the App Works

Home Page:
Displays a list of all available chat rooms and topics. You can browse, join, or create new ones.

Creating a Room:

Click the “Create Room” button.

Give your room a name, select a topic, and add a brief description.

Once created, others can join and chat within it.

Chat Interface:

Each room displays a real-time discussion thread.

Type your message in the text box and send — it appears immediately.

You can see who’s active in the room.

User Profiles:

Click on your profile to edit your bio, avatar, or manage your rooms.

You can view other users’ profiles to see what topics or rooms they engage in.

Search & Explore:

Use the search bar on the homepage to find rooms, users, or specific subjects.

Admin Panel (optional):

Access via /admin if you’re a superuser to manage users, rooms, and topics.

🧩 Tech Stack

Backend: Django 5+

Frontend: HTML, CSS, Bootstrap

Database: SQLite (local) / PostgreSQL (production)

API: Django REST Framework

Image Handling: Pillow
